# אורן מזרחי · פרומו 15 שניות (1080×1920, Reels)

`oren-mizrahi-promo-15s.mp4` — H.264 High, 30fps, AAC 192k, 15.0s.

## הקונספט: "מהפרוכת אל הטלית"
הסרט הולך בדרך של חתן בר המצווה, בעולם החזותי של האתר:
1. **0–2ש׳ הוק:** פרוכת בכחול חצות עם כתר ורקמת כסף, השם נכתב בכתב היד של אורן, והפרוכת נפתחת אל האור.
2. **2–4.5ש׳ ההבטחה:** פסי הטלית נארגים לרוחב המסך, והכותרת של האתר עולה שורה אחרי שורה: "מעל 20 ילדים עלו לתורה בביטחון. הבן שלכם הבא."
3. **4.5–8.6ש׳ איך זה עובד?:** פס התכלת הרחב מציף את המסך. הפסוק "ואהבת לרעך כמוך" בסת"ם מאבד טעמים ואחר כך ניקוד, ושלושת הצעדים נקשרים כקשרים על חוט.
4. **8.6–11.6ש׳ המלצות:** כרטיס הפסוק מתעצב לטלפון, ושלוש הודעות אמיתיות של הורים מהאתר מגיעות עם "מקליד…".
5. **11.6–13.2ש׳ יחס חם:** הטלפון עף החוצה, התמונה מול ארון הקודש נוחתת במסגרת, והעטרה המשובצת נמתחת ונדבקת עליה.
6. **13.2–15ש׳ סיום:** העטרה יורדת כתריס, וחושפת את הלוגו (השם), "מלמד בר מצווה בירושלים", הכפתור "מוזמנים לדבר איתי" והדומיין.

כל הטקסטים לקוחים מהאתר (ההמלצות קוצרו לציטוט אחד-שניים מתוך ההודעה המקורית). הגופנים (felix007, Gveret Levin, Stam), הצבעים, הסמלים (עטרה, כתר) והתמונות הם קבצי האתר עצמו.

## מבנה
- `src/composition.tpl.html` — הקומפוזיציה: HTML/CSS, ופונקציית `renderFrame(f)` שמחשבת כל פריים מהזמן בלבד (springs, easing, masks, מצלמה).
- `src/build.py` — מזריק את סמלי ה-SVG של האתר ואת אייקון הוואטסאפ ל-`src/composition.html`.
- `src/render.js` — מרנדר פריימים עם Chromium (Playwright).
- `src/audio.py` — פסקול מקורי שסונתז בקוד (פד בדו מז׳ור ואפקטים מסונכרנים לתנועות). בלי סמפלים ובלי מוזיקה של צד שלישי, אז אין בעיית רישיון.

## רינדור מחדש
```
python3 src/build.py
node src/render.js frames build/frames 0 449 1
python3 src/audio.py build/soundtrack.wav
ffmpeg -framerate 30 -i build/frames/%04d.png -i build/soundtrack.wav -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p -profile:v high -movflags +faststart -c:a aac -b:a 192k -shortest oren-mizrahi-promo-15s.mp4
```
